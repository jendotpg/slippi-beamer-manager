# Slippi Beamer Manager

[![Download](https://github.com/user-attachments/assets/0f155c5c-bd25-45fb-99f7-db055a380e12)](https://github.com/jendotpg/slippi-beamer-manager/releases/latest)

A [Beamer](https://github.com/jendotpg/slippi-beamer) is a special USB stick that can send Slippi Replays over Wifi in addition to keeping them in storage. It works together with [Beamer Manager](https://github.com/jendotpg/replay-manager-for-slippi) and [Replay Reporter](https://github.com/jmlee337/replay-manager-for-slippi) to completely eliminate the need for USB handoffs. If you're already comfortable with Replay Reporter, you shouldn't need any technical expertise to get this up and running! For setup instructions see [the Beamer guide here](https://github.com/jendotpg/slippi-beamer/blob/esp-32/README.md).
